pj_scene_common owns the backend-agnostic layered scene dock framework shared by scene widget families. Start with `include/pj_scene_common/scene_layer.h`, `layer_factory.h`, and `scene_dock_widget.h`; rendering-specific view state belongs in the 2D/3D families, not in this module. `layer_params.h` adds two free helpers (`serializeLayerParams`/`applyLayerParams`) that round-trip a layer's settings through its `xmlSaveState`/`xmlLoadState` as a portable XML string — the backbone for copy/paste of layer parameters between same-family layers.
